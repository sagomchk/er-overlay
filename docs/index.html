닉네임을 조회하고 표시할 정보를 고른 뒤, 방송 프로그램의 브라우저 소스에 붙여 넣을 오버레이 링크를 만들어요.

안내

  • 방송 화면의 오버레이는 3분마다 갱신돼요.
  • 최근 순위와 일일 점수 변화는 최근 60경기 중 랭크 경기만 골라 계산해요. 최근 60경기에 랭크 경기가 없으면 최근 순위는 표시되지 않아요.
  • 일일 점수 변화는 한국 시간(KST) 기준 오늘 0시 이후 랭크 경기의 RP 변화 합계예요.
  • 랭킹은 특정 서버가 아닌 모든 서버를 합친 전체(글로벌) 순위예요. 이터니티·데미갓 컷 점수도 전체 순위의 300위·1000위 점수를 기준으로 하고, 10분마다 갱신해요.
